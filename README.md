# Каталог товаров

Учебный проект на HTML, CSS и JavaScript: каталог с поиском,
фильтрами и адаптивными карточками товаров.

[Открыть сайт](https://belixiom.github.io/product-catalog/)

## Возможности

- Поиск по части названия без учёта регистра и пробелов по краям запроса.
- Фильтрация по максимальной цене, включая указанную границу.
- Переключатель «Только в наличии».
- Совместная работа поиска и фильтров.
- Применение фильтров кнопкой или клавишей Enter.
- Проверка пустого и отрицательного бюджета.
- Сброс фильтров и показ всех товаров.
- Отображение количества найденных товаров и статуса наличия.
- Адаптивная сетка карточек.
- Сортировка по цене: по возрастанию, по убыванию и исходный порядок.
- Скидка 10% с сохранением исходных цен товаров.
- Фильтрация по бюджету учитывает цену со скидкой.
- Кнопка «Показать все товары» сбрасывает фильтры, сортировку и скидку.

## Технологии

- HTML — структура страницы и форма.
- CSS — оформление, Flexbox, Grid и медиазапросы.
- JavaScript — обработка данных, DOM и события.
- GitHub Pages — публикация сайта.

Без фреймворков и сторонних библиотек.

## Структура проекта

- index.html — разметка каталога и формы.
- style.css — оформление и адаптивная сетка.
- script.js — данные товаров, фильтрация, поиск и обновление страницы.

## Локальный запуск

1. Скачайте репозиторий или клонируйте его:
   git clone https://github.com/BeLiXioM/product-catalog.git
2. Откройте index.html в браузере.

Установка зависимостей и сборка не требуются.

## Что я изучаю в проекте

Проект создан в процессе обучения.
Код пишу, проверяю и дорабатываю самостоятельно, с объяснениями
и подсказками по новым темам из открытых источников.

На практике использованы функции, массивы объектов, методы
filter, find и map, обработка строк, создание DOM-элементов,
события формы и управление состоянием элементов интерфейса.

## Ограничения

Данные товаров хранятся в JavaScript-файле.
Сервер, оформление заказа и сохранение фильтров между
посещениями пока не реализованы.
