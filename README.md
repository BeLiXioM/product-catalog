# Каталог товаров

Учебный проект на HTML, CSS и JavaScript: каталог с поиском,
фильтрами и адаптивными карточками товаров.

[Открыть сайт](https://belixiom.github.io/product-catalog/)

## Возможности

### Каталог

- Поиск по части названия без учёта регистра и пробелов по краям запроса.
- Фильтрация по максимальной цене и наличию.
- Сортировка по цене и возврат к исходному порядку.
- Скидка 10% без изменения исходных цен.
- Фильтрация по бюджету с учётом скидки.
- Применение параметров кнопкой или клавишей Enter.
- Проверка пустого и отрицательного бюджета.
- Сохранение настроек и восстановление после перезагрузки.
- Сброс параметров кнопкой «Показать все товары».
- Адаптивное отображение карточек.

### Корзина

- Добавление доступных товаров по отображаемой цене.
- Объединение товаров с одинаковыми id и ценой.
- Раздельные строки для одного товара с разными ценами.
- Изменение количества кнопками «+» и «−».
- Подсчёт количества единиц и общей стоимости.
- Удаление отдельных строк и очистка корзины.
- Сообщение о пустой корзине и блокировка кнопки очистки.
- Сохранение корзины между перезагрузками.
- Проверка сохранённых данных и поддержка старых записей без quantity.

### Загрузка и обработка ошибок

- Загрузка товаров из products.json через fetch.
- Проверка HTTP-ответа, формата массива и данных товаров.
- Отображение состояния загрузки и понятного сообщения об ошибке.
- Блокировка кнопок фильтрации до успешной загрузки.
- Повторная попытка загрузки.
- Обработка повреждённых сохранённых настроек и корзины.

## Технологии

- HTML — разметка, формы и семантические элементы.
- CSS — оформление, Flexbox, Grid и медиазапросы.
- JavaScript — ES-модули, DOM, события, массивы и объекты.
- Promise, async/await и fetch — асинхронная загрузка.
- JSON и localStorage — сохранение данных в браузере.
- Git и GitHub Pages — контроль версий и публикация.

Без фреймворков и сторонних библиотек.

## Структура проекта

- index.html — разметка каталога, формы и корзины.
- style.css — оформление и адаптивность.
- script.js — запуск приложения, обработчики событий и управление интерфейсом.
- products.json — данные товаров.
- api.js — загрузка и проверка ответа сервера.
- validation.js — проверка данных товаров.
- filters.js — фильтрация и поиск.
- sort.js — сортировка товаров.
- discount.js — расчёт скидки с копированием объектов.
- render.js — создание карточек каталога.
- cart.js — подсчёт суммы и количества, сохранение и восстановление корзины.


## Локальный запуск

1. Скачать репозиторий или клонировать его через Git.
2. Открыть папку проекта в VS Code.
3. Установить расширение Live Server.
4. Нажать правой кнопкой на index.html и выбрать Open with Live Server.

Проект нужно запускать через HTTP-сервер:
открытие index.html напрямую через file:// не подходит
для работы модулей и загрузки JSON.

## Ограничения

- Данные загружаются из статического JSON-файла, серверной логики нет.
- Оформление заказа, оплата и учётные записи не реализованы.
- Настройки и корзина хранятся только в текущем браузере и не синхронизируются между устройствами.
- Корзина сохраняет цену на момент добавления и не сверяет её с последующими изменениями каталога.
